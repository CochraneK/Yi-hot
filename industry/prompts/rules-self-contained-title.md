
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 项目名 / 活动名 / 政策名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是编号 / 代号 / 没信息量的 teaser（如 "No. 2026-15"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "No. 2026-15" + 来源 "某基金会年度报告" → "某基金会 2026-15 号年度报告发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构时，用上位词（如"某公益基金会"）兜底，绝不凭"行业常识"编一个具体机构 / 项目 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：解读 / 分析 / 评论 / 盘点 / 指南这类解释、分析、教程或评论标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的项目、机构或新数据，就改写成“发布 / 启动 / 上线 / 披露”。只有原标题明确宣布了发布、启动、上线或披露，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、项目、活动名。
   例：原标题 "如何理解中基透明指数的变化" → "如何理解中基透明指数的变化"，不能写成 "基金会中心网发布新透明指数"。
   例：原标题 "如何为救灾组织志愿者队伍" + 来源和正文明确是中国乡村发展基金会 → "中国乡村发展基金会如何为救灾组织志愿者队伍"，不能只写成缺主体的 "如何为救灾组织志愿者队伍"。
