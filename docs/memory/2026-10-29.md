## 六、prefilter 命中率结构实测（2026-10-29，含对已上线截断的回归）

2. **命中率 34.8%→50.8%，但提命中率不省钱**：命中的 640 token 恒等于 system prompt
   （各分档都是 638-640，连 19k 的样本也一样），单价 ¥0.02/M，只占单次成本 1.8%。
   未命中的正文 618 token 占 87.4%，output 19 token 占 10.8%。
   → **prefilter 的钱 = 正文的未命中 token。"提命中率"是死路，"砍正文"才是活路。**
3. **没有更便宜的模型可换**：全站跑 `deepseek-flash` @ api.deepseek.com（¥1/M、缓存 ¥0.02/M、
   output ¥4/M，高峰 ×2）。`zhipu` 预设在 `providers/llm.ts` 里但**无价格表条目、无密钥**。
4. **无重复调用可省**：7 天 8,363 次调用对应 8,274 篇，基本 1:1。
5. **【最优解，等待落地】把 800 字预算从「首 800」改成「首 400 + 尾 400」，成本不变、判定更好。**
   68 篇长正文（>1600 字）逐篇跑四种取法，与全文判定对照：

   | 取法 | 总字数 | avg_in | 改判 | 误挡PASS | 漏挡BLOCK |
   |---|---|---|---|---|---|
   | 首 800（现在） | 800 | **1,351** | 3 | 1 | 2 |
   | **首 400 + 尾 400** | 800 | **1,350** | **0** | **0** | **0** |

   | 首 800 + 尾 400 | 1200 | 1,578 | 1 | 0 | 1 |

   → **首 400+尾 400 与首 800 字数完全相同（1,350 vs 1,351 token），判定却全对。**

   带去 PASS；首 400+尾 400 的两端均分让 BLOCK 信号进得来。3 个分歧案例里 B 全对、

## 部署与验证的坑（本次踩到）

- **容器里跑测试用的是镜像内的旧代码**，`-v` 挂载宿主机 `/opt/yihot` 的文件才生效；
  build 之前想快速迭代必须逐个 `-v` 挂载改动文件。
- **CI 库必须每次重建**：`runtests-ci.sh` 里没有 DROP/CREATE（`api` 容器无 psql），
  要在宿主机 `docker exec aihot-db-1 psql -c 'DROP DATABASE IF EXISTS aihot_ci' -c 'CREATE DATABASE aihot_ci'`。
  用脏库跑全量会假失败（本次 signals.test.ts 的队列断言被前面测试的队列残留卡住，
  干净库上 4/4 通过）。
- **`sources.config` 是 NOT NULL**：测试里 INSERT 不能传 NULL，要写 `'{}'::jsonb`。
- **验证「跳过」不能只看 analyses 有没有新记录**：改完后队列里可能恰好没有那 29 个源的稿。
  可靠做法两条并行：① 查某时刻后 `prefilter_article` 的 receipt 按源分组，skip 源应为 0
  ② 容器内跑一次性脚本 `loadAnalyzeInput` 打印 `input.source.skipsPrefilter`（本次两条都做了）。
- 首尾取样同样用运行时脚本验证（打印 `prefilterUser` 输出的正文段），
  **别去查 `receipts.request`**——复用的 receipt 不存 request，会拿到 NULL 还以为是改坏了。
- **线上验证"跳过"的最干净办法**：容器里直接 `runAnalysis(loadAnalyzeInput(id))`。
  subject 没变 → 后续步骤复用旧 receipt，**零花费、零写库**，只有 prefilter 是短路还是真跑能看出来
  （`receipt=null` + reason 含"跳过预筛"= 跳过；有 receipt + 模型 reason = 没跳过）。
  实测 6 篇 skip 源全跳过、6 篇非 skip 源全跑，一次跑通。
- **PostgreSQL 的 `ORDER BY <bool> DESC` 把 NULL 排在最前**（不是最后）。本次验证脚本
  `ORDER BY (config->>'skipPrefilter')::boolean DESC LIMIT 6` 拿到的 6 条全是**没配这个键**的源，
