> 2026-10-23 · 信源扩充工作的**收口清单**：已纳入哪些、哪些省份/地方/部门仍空缺、以及哪些尝试失败了、为什么失败。
> 配合 [SOURCE_EXPANSION.md](SOURCE_EXPANSION.md)（清单外补充框架）与 [SOURCE_CANDIDATE_TRIAL.md](SOURCE_CANDIDATE_TRIAL.md)（候选治理）一起看。

## 数据口径（先读这一节，否则数字会误读）

- **`industry/sources.json`**：人工维护的 seed，**66 条骨干源**（`web_list` 40 / `json_list` 17 / `rss` 8 / `search` 1）。它**不是**线上全貌。
- **线上数据库**：实际约 **102 个启用源**，另有 **36 个 `web-probe-*` 探测源只在数据库、不在 `sources.json`**（运行态自动生成，改它们只能 `UPDATE sources`）。
- **`sel.tsv`**：一次真实采集的**入池样本（354 条 selected）**，用于反推"哪些源真的在出稿"。它是**快照，不是实时**；线上以 PostgreSQL 运行时为准。
- **唯一口径**：看**入池率**（`publications.selected`），不看 found / created / 解析条数。技术接通 ≠ 内容对口。

## 三、尝试失败清单（哪些失败、为什么失败）

| 尝试对象 | 类型 | 失败 / 受限原因 | 处置 |
| :--- | :--- | :--- | :--- |
| 卫健委数据 API | 数据接口 | HTTP **412** 拒接 | 只接新闻栏，数据接口维持拒接（不绕过） |
| 公安部数据 API | 数据接口 | HTTP **521** 拒接 | 只接新闻栏 |
| 9 个 SPA / JS 渲染站点（含发展研究基金会等高质量机构） | 网页 | 首页 0 `<a>`、列表异步加载，当前架构抓不到 | 等**无头浏览器渲染器**（架构项，见下） |
| 4 个需登录 / 非 feed 源 | 公众号 / 内部 | 无公开 feed、需登录 | 放弃，不在扩充范围 |
| 4 个日期 / 内容不可解析源 | 网页 | 发布时间缺失或正文不可结构化 | 低优先级，或靠搜索源补 |
| everyinfra 预算归零（14 源） | 采集预算 | `budgets.everyinfra.per_day=0` → 8 公众号 + 3 微博 + 3 小红书停摆，`fail_count` 不自动禁用 | 恢复 `per_day=150` |
| 21 个零入池源 | 内容对口 | found / created 有数、`selected=0` | "留观察一周"再决定去留 |
| 聚合热榜（tophub / NewsNow 等） | 热榜 | 69% 链接被替换成搜索页，拿不到发布时间 | **已证伪**，不采用 |
| 邮件源 `collect.py` 被 403 | 投递 | `urllib` 默认 UA `Python-urllib/3.x` 被 web 边缘中间件按 UA 拦截 | **已修复**（加浏览器 UA，commit `55fa518`） |

> 失败原因四大类：**对端直接拒绝（API 412/521）**、**需 JS 渲染（SPA）**、**需登录 / 非 feed**、**日期 / 内容不可解析**。前两类是硬伤，后两类低优先级或靠搜索源补。

## 四、与 60 行原始清单的对账

> 用户手上的 60 行原始候选清单，10-23 复核：**已接 37 / 60（≈62%）**。

未接 23 条分类：

| 未接类别 | 数量 | 性质 |
| :--- | :--- | :--- |
| 对端直接拒绝（API 412/521 等） | 6 | 真接不了（但区分"数据 API 拒接"≠"新闻栏可抓"） |
| 需 JS 渲染（SPA） | 9 | 当前架构抓不到 |
| 需登录 / 非 feed | 4 | 放弃 |
| 日期 / 内容不可解析 | 4 | 弱相关边角 |

**核心结论**：23 条未接里 19 条是硬伤，**62% 基本是那份清单的天花板**；真正还能大幅扩量的空间在清单外——中央部委新闻栏、智库 / 数据层、以及**搜索源横向复制**。

## 附：纪律提醒（加源前必看）

- **入池率才是唯一口径**：9 条 A/B 类正式媒体全接成、全 0 入池的教训在前。
- **不绕过**：中央部委只接官网新闻栏，绝不碰已拒接的数据 API。
- **验证必含真实采集**：只回填不采集是假象（列表页会把精度 / 旧值覆盖回去）。
- **恢复停用源要三列同改**：`enabled=true` + `health='ok'` + `fail_count=0`。
- 改完 `sources.json` 必须走部署纪律（scp → `docker cp` → `node scripts/seed.ts`；改 `enabled`/config 不会经 seed 同步，需直 `UPDATE sources`）。
