# Yi-Hot 使用指南（给合作方 / 负责人）

> 这份指南**只讲怎么用**，不涉及任何技术维护。遇到问题直接找文末联系人。

## 一、这是什么

Yi-Hot 是一个**公益资讯聚合站**：自动收集政府、国际组织、基金会、媒体等关于「儿童权益、慈善治理、公益合作机会」的公开信息，由 AI 筛选后，整理成一条条带**中文标题 + 摘要 + 原文链接**的卡片。你不用自己到处刷新闻。

## 二、最快上手的三种方式（任选其一）

**1. 直接打开网站看（推荐）**
地址：**http://49.233.72.222/yihot/**
- 默认是「精选」；点 **「全部动态」** 看完整信息流，按时间倒序。
- 点开任意一条看摘要；想深读点 **「原文链接」** 跳到来源网站。
- 顶部可按**主题**筛选（儿童权益、慈善治理、合作机会、社会组织等），也支持关键词搜索。

**2. 订阅邮件，被动接收（最省事）**
- 打开 **http://49.233.72.222/yihot/subscribe** ，填邮箱 → 收一封确认信点一下 → 之后自动收到**每周 / 每月**公益总报。
- 不想看了，邮件里点「退订」即可；每封邮件彼此看不到对方地址。

**3. 只盯某一类**
- 网站上筛选后收藏链接；或订阅后在邮件里挑相关条目。
- 想让系统**多关注某类话题 / 某家机构 / 某个信息源**，告诉维护人加进去即可（见文末）。

## 三、能指望它做什么

- ✅ **省时间**：持续检查已配置的公益来源，只把对公益行业有用的挑出来。
- ✅ **可信可溯源**：每条都带来源链接，不替你下结论。
- ⚠️ 它不是新闻首发地，也不替你写稿——只做「筛选 + 摘要 + 汇总」。
- ⚠️ 内容来自公开网页/邮件，偶有遗漏或延迟，重要决策请以原文为准。
