## 三种中性标记

1. `overlapPossible=true`：前端展示「内容可能重合」，不是确认重复、也不是剽窃判定。目前对 NewsIQ、AI快讯、XABC News、神灯AI热点、AI Pulse、日耕 AI 熱點等综合聚合标注；待真实新闻样本可以复核。
2. `strategy=link`：显示「尚未接入同步」，站点仍可列入正式邻域。链接不触发抓取。
3. 最近一次 RSS/API 抓取 `ok=false`：保留有效登记卡片，提示「同步暂不可用」，允许用户前往原站阅读。历史旧稿不等于最新新闻。

原有 `freshness` 按源文章 `published_at` 的时效提示继续保留，但过时也不触发排除。RSS/API 优先不变；不因为这些提示自动启用主站 sources Seed、开启全文或模型分析。日报/周报原有轮换策略不变。

## 验收、风险和回滚

- 离线测试确保正式同系/其他两块、旧 API 缺值兼容、内容重合/同步失败不被错误降级；CI 必须通过 TypeScript、Web、后端 PostgreSQL 与 Docker。
- 整体页面保持三层，候选信息折叠。网络失败后的最新站点状态展示，需要部署后由真实 worker/DB 验收。
- 没有改数据库 schema、删除条目、开启收费模型、改变抓取任务或触及用户数据。GitHub 合并不等于腾讯云发布；生产仍需要独立部署。
