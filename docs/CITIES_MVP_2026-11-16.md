# YiHot006 · 城市地图 MVP（2026-11-16）

## 状态与责任边界

代码分支 `feat/city-news-map-20261116`，不是腾讯云部署证明，也不是全量新闻已建立精确地点索引。上轮 Yihot005 的「368 个地点代表点」在此仓库主分支未发现可复用的完整数据资产，故本轮不宣称已经导入 368 条，也不把没有来源的坐标伪装为采集结果。

本轮实现：`/cities` 城市入口（保留手机底栏原结构，从「动态」和「更多」到达）；约 60 个常见城市中心的静态词典；从当前页的**公开标题与摘要**识别城市线索，按城市使用既有 `/api/site/pool?q=...` 检索；中国/世界两种经纬度示意视图，地点数随当前页变化；点击地名进入城市检索；可选、主动点击后才加载 OpenStreetMap 实地图；浏览器本地保存城市选择，新闻标题只有一个匹配城市时展示「当地」。

**这是地点提及而非事件发生地**。组织名称、报道地点、募捐覆盖地、事件地点不能自动互换；地图落点是城市代表点，不是地点精确坐标。地区下拉仅在**当前页**筛选，并不代表全库的省市检索。未识别地点的新闻仍留在 `/all` 动态列表。本轮绝不报告地理索引覆盖率。

## 位置与数据合同

- 唯一词典：`apps/web/app/features/cities/geo.ts`。城市 id 稳定，包含城市、地区、国家、ISO 国家码、经纬度和常见名称；目前是保守的公开地理示意表。
- 来源：`/api/site/pool`；可见性、发布时间门槛、摘要许可、公开查询由原 publication 层执行。不直接查询 DB，不从已撤稿/未发布稿提取地名，不新增 API/采集、数据库迁移、worker 任务、付费调用或腾讯云配置。
- UI：`apps/web/app/routes/cities.tsx`，位置线索只投到**本页 40 条**。选城市时，`q` 是文本匹配，不能推导为全库事件级地理筛选。
- 当地标记：`apps/web/app/features/feed/FeedItem.tsx` 和 `reader-city.ts`。默认不定位。用户手动选城市后本地保存一个 ID，或主动点击「按 IP 估计」才发浏览器请求到 ipwho.is；不会保存 IP，也不会把用户城市放进公开缓存。仅标题单一地点匹配时标记。地图 OpenStreetMap iframe 也是用户点击后加载。浏览器禁用 Storage、IP 不可识别、代理定位偏差时不强制显示「当地」。

## 安全与第三方

- 浏览器请求 ipwho.is 仅在用户主动点击后发送；该服务获得连接 IP，受服务商的免费额度、CORS、可用性与使用条款约束。生产上线前，请站点运营者确认商业/公益用途许可、隐私声明、国外服务可访问性；必要时关掉此按钮，仅保留手选城市。不能把免费 API 当作长期 SLA。
- 点击「查看实地图」加载 OpenStreetMap，地图提供方会见到请求信息，页面已说明。
- 不采集浏览器精确定位/GPS，既不收集真实 IP 到自建 DB，也不把访客地理信息写到服务器缓存或 Git。
- 首次上线应从线上实际公开数据抽样，尤其避免「北京某基金会在四川开展」被误认作北京本地新闻；歧义条目宁可不显示当地。

## 验收 / 发布闸门

1. GitHub Check：typecheck、Web build、Web tests、现有安全/回归测试通过。新增 `apps/web/tests/cities.test.ts` 覆盖英文别名边界、同新闻多城市、摘要-only 不标当地、空 IP 回退、地图 URL。
2. 空数据、无城市词、双城市词、纯英文地名、中文地名、禁用 Storage、IP 请求失败、搜索繁忙、发布门槛、移动端小屏、深色模式、地图离线等路径抽样。
3. 运营者须确认 ipwho.is 许可和隐私文案；不确认时在生产关闭或移除外部 IP 按钮。
4. GitHub 合并不等于发布。腾讯云须按本仓库部署流程更新 Web，并实测 `/yihot/cities`、`/yihot/all` 的当地标签与旧界面、无新付费任务。
5. 回滚仅撤销对应 Web 路由、入口、辅助词典、当地 UI；既有公共数据和订阅不变。

## 后续升级（不能在本轮假称已实现）

- 单独的地理信息规范：`article_id / fact_id / story_id`、`place_id`、`scope`（event/publisher/affected/mentioned）、`confidence`、`evidence_text`、`source_url`、`model_version`、`verified_at`、`precision`、`status`，并区分多事件、多地区与省级代表点。
- 服务端公用读层依可见性门槛输出独立 `geo` 索引，支持全国、省、市、附近半径与时间筛选，以及正确的全量地理统计，而不是用 `q` 文本搜索替代地理过滤。
- 历史新闻可先使用离线规则回填与抽检，不反复调用付费模型；误报/漏报有人工纠错页和撤稿同步。达到预设准确度才批量启用。
- 确实需要自动 IP 地理信息时，优先合规代理层或自托管地区库，按国家/省/市粗粒度匹配，不把 IP 放入共享缓存，保留关闭与手动纠错。
- 补充更多城市/地区与可靠的地理底图；提高地图/列表的手机操作性，避免集中堆积标签、遮挡和无意义的全球代表点。
