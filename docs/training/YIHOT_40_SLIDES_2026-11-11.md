# 01｜YiHot 是什么

- 面向公益与儿童权益的信息发现、整理和追踪系统
- 独立定制于开源 AIHOT；不是任何公益机构的官方平台
- 不替代一手原文与专业判断

# 02｜它解决什么问题

- 信息分散于政府、机构、媒体、邮件与开放网络
- 重复检索和重复阅读消耗从业者时间
- 让发现、理解、跟踪形成可复核链路

# 03｜从发现到跟踪

- 发现：网页、RSS、搜索与邮件
- 理解：去重、相关性、摘要、分类、事件归组
- 跟踪：动态、热点、主题、周报与月报

# 04｜读者第一次打开

- 进入动态列表，按日期与主题筛选
- 摘要是线索；打开原文核实事实和日期
- 重要事项交叉检查其他独立来源

# 05｜为什么不自动当媒体

- 不是新闻首发和事实鉴定服务
- 只默认展示摘要、标题及来源链接
- 不擅自转载全文或代替机构对外表态

# 06｜移动与桌面

- 移动端核心路径：总报、动态、热点、主题、更多
- 桌面端侧栏承载更多低频入口
- 入口简洁，但能回到证据与原文

# 07｜报告与订阅

- 日报、周报、月报按自然周期组织
- 订阅须确认，支持退订
- 推送周期和实际交付情况必须核查

# 08｜事件热点如何理解

- 独立发布主体的报道比转载次数重要
- 时间衰减决定热点的时效性
- 单靠搜索命中不能冒充一手权威来源

- 政府监管部门与各级政务网站
- 公益机构、行业媒体、国际组织和研究机构
- 发布者分类与采集技术方式彼此独立

# 17｜五层阅读框架 I

- 政策与治理：法律、监管和实施
- 国际组织与研究：指标、研究与全球趋势
- 公益机构与执行：项目、服务与实践

# 18｜五层阅读框架 II

- 行业生态与合作：募资与合作信息
- 社会事件与舆情：案例、进展、公共关注
- 五层可以交叉，不是权威高低榜

# 19｜信源怎么新增

- 先确认新增的业务价值与真实原始页面
- 候选 → 试抓预览 → 审核 → 隔离启用
- 观察入池、时间精度、重复与失败类型

# 20｜一篇文章的生命周期

- 来源发现 → 链接与发布时间规范化
- 相关性初筛 → 评分 → 摘要/标签 → 发布
- 保留原始出处、时间与处理记录

# 21｜发布时间和收录时间

- 原文发布时间来自原站记录
- 系统首次发现日期是另一个独立字段
- 旧文回填不能冒充今天新发生

# 22｜为什么会误判

- 导航页、登录页、广告可能被识别成文章
- 无日期不应自动标记为今天
- 事实关键环节须抽样回到原文

# 23｜多重转载如何计数

- 官网、RSS 和搜索可能发现同一篇稿
- 按真实发布主体和原始链接建立关联
- 不可把多个技术入口当成独立证据

# 24｜版权与采集权限

- 网站能打开不等于允许批量抓取或全文转载
- 技术接口健康与版权授权分开审核
- 遇到账号/验证码/明示禁止不得绕过

# 25｜AI 模型是分阶段的

- 预筛、评分、理解、摘要、结构化等阶段可分别选模型
- 默认、阶段变量和后台覆盖可能不同
- 模型选择应结合质量、延迟与真实回执

# 26｜DeepSeek Flash 切换

- 仓库已有 deepseek-flash 非思考默认示例与切换脚本
- 脚本不覆盖后台手动指定的模型
- 有 Git 代码不证明腾讯云已切换

# 27｜AnyDoor 的成本边界

- 免费池可因限流或上游故障而回退
- 回退到 DeepSeek 会产生额外费用
- 核查回执中的实际 service、model、币种

- 模型 token 计费与搜索 API 次数计费是两本账
- 本地估算价格与供应商实扣可能不同
- 回填和日常新稿应分账

# 30｜队列和积压

- 采集任务、模型处理和发布任务异步运行
- 付费额度耗尽不应导致无限失败重试
- 先看真实队列与处理量，不以列表停滞猜原因

# 31｜削峰与背压

- 新稿优先、历史回填预算受限
- 低价值采集可以降频，但不等于删除历史
- 队列可持续以积压趋势、费用与延迟检验

# 32｜运营每日看什么

- 信源失败和采集延迟
- 新增内容质量与队列异常
- 模型实际调用及预算告警

# 33｜运营每周看什么

- 抽样比较原文、摘要、相关性与时间
- 按主题和来源检查覆盖缺口
- 梳理重复、误筛和失效信源

# 34｜运营每月看什么

- 模型/搜索/服务器费用对账
- 报告和订阅交付是否可靠
- 保存备份恢复演练与权限审计结果

# 35｜管理员后台

- 信源、模型与评测、用量成本、运行、审计记录
- 新增源先试跑再正式采集
- 明确谁有权改模型、额度与订阅

# 36｜三个事实层

- GitHub：功能代码与示例配置
- 服务器/数据库：实际部署与运行状态
- 供应商账单：实际调用与扣费事实

- 文档写完成 ≠ 生产服务成功
- 静态测试通过 ≠ 真实邮箱与采集源可用
