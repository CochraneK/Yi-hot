## 4. 硬约束：备案

1. **域名解析到中国大陆服务器的 80/443 必须先 ICP 备案**。未备案域名在腾讯云会被拦截，这不是"能不能配"的问题，是接入层直接拒绝。
2. **`.news` 不在工信部批复的域名后缀名单内，无法备案**（多源一致）。买 `.news` + 北京机房 = 死路。
3. **备案的隐藏门槛比域名本身更关键**：资讯/新闻类站点备案需《互联网新闻信息服务许可证》作为前置审批，而该证**只有中国境内依法设立的法人可以申请，个人不能办**。判断标准是**内容性质**（是否涉时政类采编/转载），不是站点大小或访问量。
4. 本项目聚合转载公益动态与政策文件，**很容易被认定为资讯类**。因此「个人主体 + 时政转载 + `.cn` 备案」这个组合基本走不通。

## 5. 三条可行路径

| 路径 | 做什么 | 成本 | 代价与风险 |
| --- | --- | --- | --- |
| **A · 维持现状（推荐）** | 继续 IP + 路径访问，不买域名 | ¥0 | 无 HTTPS、分享不体面；邮件仍是 `qq.com` |
| **B · 买 `.cn` 但不绑主站** | 只做邮件发件域、短链跳转、对外名片 | ¥35–55/年 | 主站仍是 IP；跳转页是否也算"信息服务"需自行确认；不能挂在国内机 80/443 |
| **C · 海外 VPS + 域名** | 香港/新加坡/日本主机 + `.news` 或 `.cn`，不备案 | 主机 + 域名 | 延迟、邮件送达率、数据出境、免备案≠免监管 |

**注意路径 B 的常见误解**：买了 `.cn` 不等于能解析到腾讯云北京。不备案就只能指向海外主机，或者根本不解析。

## 6. 海外 VPS：需要核实什么

**本节没有价格结论，只有核实清单。** 我们不掌握该市场的实时报价，且线路质量必须实测，不能照抄测评。

### 6.1 必核字段

| 维度 | 要问清楚的问题 |
| --- | --- |
| 机房地区 | 香港 / 新加坡 / 日本 / 美国西部？到国内三网延迟差的不是一点 |
| 配置 | ≥2 核 2GB、≥40GB SSD（当前 PostgreSQL 约 90MB，但镜像与日志吃盘） |
| 带宽/流量 | 月流量上限、超流量计费、是否限速 |
| 线路 | 是否 CN2 GIA / 直连优化；普通国际线路晚高峰会掉到不可用 |
| 计费 | 月付/年付价、是否支持支付宝、退款政策 |
| 合规 | KYC 要求、AUP 是否限制"新闻聚合/爬虫/代理" |
| 运维 | 是否支持 Docker、是否有快照/备份、是否给独立 IPv4 |
| 实测 | 国内 ping/丢包、`docker pull` 速度、**邮件投递到 QQ/163 的送达率** |

### 6.2 候选方向（仅方向，未报价）

- 腾讯云 / 阿里云国际站的香港轻量（生态一致、中文支持好，但需国际站账号）
- Vultr / DigitalOcean / Linode(Akamai)（按小时计费，适合试）
- Hetzner（欧洲，性价比高，但到国内延迟大，只适合纯后端任务）

### 6.3 信息获取渠道

- **官方 pricing 页**：唯一可信的价格来源。
- 第三方测评与 LowEndTalk / LowEndBox：可作线索，但低价套餐常超售，需自行验证。
- 不要采信"永久优惠"、"不限流量"这类宣传语。

### 6.4 迁移成本清单

- PostgreSQL `pg_dump` / `restore`（约 90MB）
- WeRSS 的 SQLite 数据目录 + `/opt/werss/.env`（管理密码、签名密钥）
- 三份 compose 覆盖文件必须齐全：`docker-compose.yml` + `compose.futureme-proxy.yml` + `compose.werss.yml`（**10-19 已因漏掉第三份导致公众号断链 21 小时**）
- `secrets/` 加密归档在新机器重新解出
- DNS 切换前把 TTL 降到 300s，保留旧机 48 小时

### 6.5 风险

- **邮件必须留在国内或改用专业 ESP**：海外 IP 向 QQ/163 发信，进垃圾箱概率显著上升；而订阅邮件是本项目的正式出口。
- **数据出境**：订阅者邮箱属于个人信息，跨境存储需要单独评估。
- **免备案不等于免监管**：内容合规责任不随服务器位置转移。

## 7. 建议与触发条件

**现在不买。** 域名是品牌问题，不是可用性问题；当前更值得投入的是采集稳定性与内容质量。

出现以下任一情况再启动：

1. 需要对外正式品牌（媒体合作、机构对接、报告署名页）。
2. 需要 HTTPS 正规证书（当前 IP 访问容易被读者当成"不安全"）。
3. 要做品牌发件域（需 SPF/DKIM/DMARC，配合订阅增长）。
4. 需要短链或 CDN。

**若启动，推荐顺序**：

1. 先买 `.cn`（¥35–39 首年），只做跳转与邮件域，**不急着备案**。
2. 若确需备案：先确认主体性质与内容定位，**联系腾讯云备案客服问清楚再买**，不要先买域名才发现备不了。
3. `.news` 只在"确定迁海外"时买，按 **5 年总成本 $114–130** 决策，不看首年 $7.96。
