# 想法台账

这份文档收的是**说清楚过、但还没做**的想法。它的用处只有一个：不让好点子随着对话滚没了。

三条维护规则：

- **做完的移到第二节**，不要留在第一节里反复出现；
- **讨论过后决定不做的移到第三节**，连同当时的理由——否则过两个月又会有人（包括 AI）重新提一遍；
- 新想法随时往下加，写清楚**是什么、卡在哪、哪天提的**。没有日期的想法，半年后没人知道它还算不算数。

「卡在哪」这一栏不是谦辞。绝大多数想法不是因为没人想到，而是因为缺一个具体的东西：一个字段、一套口径、一次扫码、一个人坐下来标几百条。写清楚卡点，等于把「以后再说」变成「补上这个就能做」。

## 三、讨论过、结论是不做

留着这一节，是为了不让同一些方案每隔两周被重新提一次。理由都来自实测，不是判断。

| 想法 | 为什么不做 |
| :--- | :--- |
| 把「评分 + 结构 + 写作」合并成一次调用 | 实测合并后总价**贵 2%**、质量更差。三段巨型提示词有 84% 命中缓存，拆开反而便宜 |
| 砍掉零产出信源省钱 | 18 个 30 天零入选的源合计每月 ¥1.23，动它们省不出钱，只损失覆盖 |
| 把搜索的回看窗口从 7 天收到 3 天 | 3–7 天这一段是搜索源入池的主力，7→3 每天砍掉约四成入池 |
| 给单一信源设「每天最多发几条」 | 会先砍掉公益时报这种汇聚型信源，它一期里就有十几条不同机构的消息 |
| 把其他衍生站的 RSS 接成本站信源 | 机器人、音视频、影视、跨境电商、营销、心理学与儿童公益没有交集，只会稀释入池率并推高成本 |
| 接台湾媒体做信源 | 立场风险不可控。中国香港只接服务型与建制机构 |
| 继续铺省级残联直连 | 直连入池率天然低，铺了也是白铺 |
| 用免费聚合接口当主通道 | 只做备用。主通道要的是「哪天坏了我知道」，不是「不要钱」 |

## 四、怎么用

- 挑活的时候从第一节里选，**优先选卡点最短的那条**——卡点写着「只是导航没接上」的，半小时能做完；写着「要有人标几百条」的，先别起头。
- 做完一条，把它从第一节剪到第二节，一行就够，不用写实现细节。
- 被证伪的想法进第三节时，**把当时的实测数字一起写进去**。没有数字的「不做」，过一阵就会被当成偏见。
